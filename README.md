# agent-team

The home of Daniel's agent team: its commands, its role prompts and settings, and its records.
`CLAUDE.md` describes the repo; `manual-steps.md` lists the steps only Daniel can take.

## Set up a machine as a host

On a machine with only Claude Code installed, open `claude` in any folder and send:

> Set up this machine as a host for my agent team. The repo is github.com/chanjdaniel/agent-team and it is private: install gh, sign me in to GitHub with it, clone the repo to ~/agent-team, then follow its SETUP.md.

The sentence is the whole of what an agent needs before it can read this private repo; from there `SETUP.md` drives the setup and asks for each step that is yours.
Say "set up as host" again in a later session to pick up where it stopped.
